# Changelog

## 0.1.0 - 2026-05-10

- Added typed HeadHunter API client based on `andy87/php-client-sdk`.
- Added generated providers, prompts, responses, schemas and `ProviderKey` enum.
- Added stable ASCII provider aliases for public API access.
- Added anonymous, Bearer token and custom authorization configuration support.
- Added English and Russian user documentation.
- Added smoke tests, OpenAPI generator tests and PHPStan analysis script.
